# Proyecto Estudiantil

Soy Matiaz Ibaceta creador de este proyecto que fue creado con el fin de proyecto de finalizacio para el area de Diseño Web que esta hecho para poder ver los laboratorios del colegio Insuco Valparaiso con sus horarios, componentes, disponibilidad (a tiempo real) y tambien su rating en estrellitas del más profesional en area de trabajo al menos optimo


# Sistema de Control de Laboratorios de Computación - Liceo

Este proyecto consiste en un sitio web adaptativo y con una estructura clara esta desarrollado con HTML5, CSS3 y un módulo de JavaScript denominado BackEnd.js. Su objetivo principal es gestionar e informar en tiempo real el estado, las especificaciones técnicas, los horarios y la disponibilidad de los laboratorios de computación del liceo.

## Características

1. Información completa
Se detalla la cantidad de equipos en cada laboratorio dentro de las tarjetas y tablas informativas. También se especifica el sistema operativo correspondiente, ya sea Windows 11, Ubuntu Linux o Dual Boot. La disponibilidad se muestra mediante indicadores visuales de Disponible u Ocupado acompañados de su horario correspondiente.
2. Navegación y Plantilla
El sitio utiliza un encabezado unificado mediante etiquetas header y nav. Esto simplifica el desplazamiento por las distintas páginas y facilita la incorporación de futuras secciones.
3. Diseño Reponsivo
La plataforma se ajusta de forma fluida a pantallas de teléfonos, tabletas y computadoras gracias al uso de CSS Grid, Flexbox y media queries.
4. Estructura Semántica HTML5
Se usaron etiquetas semánticas para organizar el contenido correctamente, incluyendo header, nav, main, section, article, aside, table y footer.
5. Monitoreo en Tiempo Real
El script BackEnd.js consulta la hora y el día del navegador para cruzarlos con la programación de clases. Con esto actualiza de manera automática, sin necesidad de refrescar la página, las etiquetas de Disponible u Ocupado, especificando la asignatura, el profesor a cargo, el bloque de clase actual y los contadores globales en la página de inicio. El Laboratorio 5 se mantiene configurado como Fuera de Servicio.
