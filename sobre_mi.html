Sobre este Proyecto

Este sitio web, Sistema de Control de Laboratorios, es un proyecto estudiantil desarrollado para gestionar la disponibilidad, las especificaciones técnicas y el horario de los laboratorios de computación del Instituto Superior de Comercio Francisco Araya Bennett. Esta construido con CSS, JavaScript y HTML hecho para ser reponsivo. Tiene (BackEnd.js) que actualiza en tiempo real el estado de cada laboratorio según su horario real de clases.
